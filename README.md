# Your Personal SafeGuard

A comprehensive emergency services platform that connects users to emergency services instantly while providing disaster alerts, safety resources, and community support.

## Key Features

- **Instant Emergency Connection**: Connect to any emergency service with one tap, sharing your pre-filled details.
- **Location-Based Disaster Alerts**: Get notifications about prone natural disasters in your area using AI.
- **Government Notifications**: Receive timely updates on weather and upcoming phenomena from official sources.
- **Emergency Profile**: Store your critical information like location, blood group, and medical details for emergency situations.
- **AI-Powered Mock Drills**: Conduct practice drills for disaster preparedness for yourself and your family.
- **AI Chatbot Assistance**: Get help with any safety or emergency-related questions.
- **Safety Resources**: Access guides, videos, and resources tailored to different natural disasters.
- **Community Reporting**: Report emergencies or hazards in real-time to create a community-driven safety network.
- **Community Forums**: Share tips, experiences, and resources with other users.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)
- Google Gemini API

### Installation

1. Clone the repository
```bash
git clone https://github.com/ankush443/your-personal-safeguard.git
cd your-personal-safeguard
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
